# Alberto-Clock
Alberto Clock is an online store for premium watches and wall clocks, where customers can browse the collection, save items to their cart and wishlist, and request custom designs or repairs. The site also includes a store locator, gallery, offers, FAQ, and a chatbot that answers product questions.

**Tools and Technology:**
- HTML5 for page structure
- CSS3 for styling, layout, and animations
- JavaScript for cart, wishlist, routing, forms, and the chatbot
- jQuery 3.6.0 for form handling and validation
- IntersectionObserver for scroll-reveal animations
- Google Maps embed for the store locator
- Background video with WebM and MP4 formats
- CounterAPI for the visitor counter
